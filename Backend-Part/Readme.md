## 为什么要专门加后端章节？

算法最终是要应用在生产环境中，完全搞算法的人少之又少，如何高效的应用和部署算法需要的是工程能力，所以提高自己的工程能力也是非常必要的。
工程能力的提升来自于理解和实践， 作为开始，我们只专注于几个比较有代表性的， 常用于AI应用开发中的技术栈和分布式架构：
* FastAPI
* Redis
* 分布式
我们会总结常用操作，笔记，以及给出演示用的项目。


## 异步操作
现代 Python 版本通过称为“协程”的东西支持“异步代码”，并使用async 和 await 语法

## 并发和并行
并发 = 同一时间段内“处理多个任务”
并行 = 同一时刻“真的同时执行多个任务”
